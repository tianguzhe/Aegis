# 局域网持续同步 v1

Mac 和 iPhone 先通过 [首次加入](LOCAL_TRANSFER.md) 或加密备份取得同一保险库，再各自在「设置 → 同步与备份」开启局域网同步。两端处于前台且已解锁时，自动交换全部条目和历史中的缺失版本。首次加入时的勾选只作用于当次导入。开关默认关闭，按本机保险库身份保存。

## 信任模型

`VaultCrypto` 从保险库密钥派生 32 字节的 `syncKey`。HKDF-SHA256 使用默认空盐和 UTF-8 用途 `aegis.lan.sync.v1`。持有同一保险库密钥的设备互信，同步服务只在前台解锁会话内持有派生密钥。要阻止丢失设备继续收到新版本，需要轮换密钥并将保留的设备迁移到新保险库身份。

## 线格式

整数使用大端，UUID 使用 16 字节，协议常量使用 UTF-8。TCP 传输禁用蜂窝与点对点 Wi-Fi。Bonjour 使用 `_aegis-sync._tcp`，域为 `local.`，服务名取当前会话随机实例 ID 的前八个字符。TXT 的 `t` 是 `instanceID || HMAC-SHA256(syncKey, "aegis.lan.sync.v1.discovery" || instanceID)` 的 Base64。对端匹配发现认证后，实例 ID 字节序较小的一端拨号。实例 ID 在该次前台服务有效期间保持稳定。

双方依次发送 `AEGISSY1 || instanceID || 临时 X25519 公钥 || 32 字节随机值`，发起方消息在前。取两条消息拼接的 SHA-256 作为握手摘要。发起方发送 `HMAC-SHA256(syncKey, "aegis.lan.sync.v1.confirm.initiator" || 摘要)`，响应方验证后发送自己的证明，使用对称的 `responder` 用途。双方用临时 X25519 共享秘密和 `syncKey` 作为盐做 HKDF-SHA256，使用 `aegis.lan.sync.v1.session || 摘要` 为 info，生成 64 字节。前 32 字节用于发起方发送，后 32 字节用于响应方发送。

认证后的帧由 UInt32 长度、ChaChaPoly 密文和 16 字节认证标签组成。长度覆盖密文和标签。每个方向从零计数，nonce 为四个零字节和 UInt64 序号。消息类型占明文首字节。

| 类型 | 内容 |
| --- | --- |
| `HELLO` 1 | header 的 SHA-256、清单 SHA-256、UInt32 版本数、UInt8 历史不完整标记 |
| `MANIFEST` 2 | 按 ID 排序的 `(UUID, SHA-256)`，每帧最多 1,024 个，按 `HELLO` 的数量读完 |
| `REVISION` 3 | 一条规范编码的加密版本 |
| `END` 4 | 空，确认版本流结束 |
| `DONE` 5 | 空，确认该端的接收和本地事务已完成 |

Header 的哈希输入依次为 UInt8 格式版本、vault ID、16 字节盐、三个 UInt32 Argon2 参数（内存、迭代、并行度）、两个 60 字节包裹密钥。版本编码依次为 UInt8 格式版本、vault ID、item ID、revision ID、UInt16 父 ID 数、按字节排序的不同父 ID、UInt32 密文长度、密文。清单摘要覆盖 UInt32 条数和排序后的全部记录哈希对。

发起方先发 `HELLO`。摘要相同后交换 `DONE`。摘要不同则按发起方、响应方的顺序交换清单，再按同样顺序发送对方缺少的版本，以 `END` 结束。两端各自在本地提交成功后交换 `DONE`。同一版本 ID 内容不一致、收到意外版本、预期版本缺失或校验失败均中断该轮。每帧至多 1 MiB，单次 socket 读取至多 64 KiB，连接上限为 60 秒。版本数量、字节和父边数沿用 `BackupLimits`。

## 入库与生命周期

`VaultSession` 严格认证本地快照，发现本地版本损坏时暂停同步并保留原数据。接收方收齐后认证每条版本并验证本地与增量的并集，拒绝循环和跨条目父链。保留已存在的缺父历史，远端缺父边须与认证清单及其不完整标记一致。`VaultStore` 在同一次 actor 调用内比较完整快照并保存，取消或保存失败会回滚未提交的写入。两端分开提交，断线后用下一轮对账收敛。不可变版本保留并发编辑冲突，永久删除标记沿用既有规则。

发现设备和本地保存后合并触发。拨号端在成功后约每 15 秒对账，单个对端连续失败三次后暂停自动拨号，待对端重新出现或本机重启同步。每台设备同时处理一轮。锁定、退出前台、关闭开关和轮换会撤销会话、取消连接并释放持有的同步密钥。已通过保存检查的事务可以完成，旧会话的结果不刷新界面。同步保持现有空闲锁定时长。

## 验证

核心测试覆盖认证与分帧、版本哈希、并集校验及过期快照和事务取消。设置 `AEGIS_TEST_LOCAL_NETWORK=1` 后运行 `LANSyncTests` 和 `LANPairingTests`，可在同一主机通过真实 Bonjour/TCP 验证双向合并、并发冲突、重连后传播永久删除标记及首次加入。Mac 与签名 iPhone 的跨设备传输和本地网络权限，需另行真机验证。
