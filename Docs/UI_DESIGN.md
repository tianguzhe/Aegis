# UI 设计规范

## 方向

Aegis 使用浅灰工作区、白色内容面板和墨绿强调色。深色模式使用石墨灰工作区与更亮的绿色文本，按钮填充色和文本强调色独立，保证白色按钮文字可读。暖金仅用于收藏及辅助提示。

字体统一为系统无衬线字体，密码使用等宽字体。主窗口内容标题 26pt、列表标题 16pt、行标题 13pt、正文 14–15pt、辅助信息 11–12pt。AegisMetrics 统一 12pt 面板圆角、8pt 控件圆角、24pt 页面边距和 56pt 工具栏高度；Mac 图标命中区域 32pt，iOS 保留 44pt。面板采用细边框，减少装饰阴影和无功能图形。

## 组件

`App/Views/DesignSystem.swift` 是共享视觉入口，主应用与自动填充扩展共同编译它。

- `AegisTheme`：背景、表面、侧边栏、选中状态、文字和边框的动态颜色。
- `AegisButtonStyle` / `AegisIconButton`：主要、次要和图标操作；iOS 图标按钮使用 44pt 点击区域。
- `AegisInput`：独立标签、输入框和焦点边框。
- `AegisSection`：小节标题与内容面板。
- `AegisSheetHeader`：弹窗标题、说明、图标与关闭入口。
- `ItemIcon`：不同类型与账号的颜色识别，无联网 favicon 请求。
- `AegisPill` / `AegisEmptyState`：辅助状态与空内容引导。

按钮禁用时使用独立的灰色背景与文字，浅色／深色模式分别适配；不再只降低整体透明度。共用按钮的绘制视图直接读取 `isEnabled`，保证封装样式同样获得真实禁用状态。禁用图标按钮不显示悬停反馈。

首次创建保险库时，主密码长度与重复输入都满足条件才允许继续。恢复密钥确认、空记录名称和备份导入缺少条件时显示具体原因；创建、解锁、保存与导入期间显示进度和明确的处理中按钮文案。保存和导入时禁止关闭当前面板，避免操作未完成就退出。

## 布局

Mac 使用可调整宽度的三栏：约 208pt 左侧分类、312pt 搜索与记录列表，剩余空间用于详情。记录采用可控的浅绿选中背景，选中与失焦都保留清晰的文字对比。列表支持上下方向键选择。

列表标题与详情工具栏对齐。搜索框显示焦点轮廓与 ⌘F 提示，数量使用小徽标，排序入口直接显示当前顺序。侧栏统一悬停反馈，底部固定保险库状态与锁定操作。

Mac 详情顶部固定显示原生操作栏：正常记录提供收藏、编辑、移至回收站；回收站记录提供恢复和红色立即删除。删除统一使用系统警告弹窗，右键菜单为辅助入口。回收站隐藏新增按钮，详情在标题下显示删除状态和到期时间。

搜索、筛选和版本更新后会重新核对选中记录；移除当前项后优先选相邻项，列表为空时清空详情。新增或编辑保存后清空搜索，并定位到保存的记录；iPhone 导航按条目 ID 跟踪，保存产生新版本不会丢失详情。编辑、设置和生成器共用一个弹窗入口，避免多个面板竞争。

Mac 按钮使用原生主次样式，表单和弹窗标题采用较紧凑的间距；iOS 保留触控尺寸。菜单栏提供 ⌘N 新建、⌘F 搜索、⌘E 编辑、⌘D 收藏、⌘⌫ 删除确认、⌘, 设置和 ⇧⌘G 密码生成器；编辑器用 ⌘S 保存、Esc 关闭，未保存内容先询问保留草稿或放弃。弹窗打开时暂停主窗口菜单命令。保存、恢复和删除后在列表底部短暂显示结果。

记录写入、同步、生物识别设置和备份导出期间阻止重复提交。未启用云服务时同步按钮禁用并说明本地使用方式。取消备份文件选择保留之前的选择和预览；加载文件时显示进度并暂时禁用关闭和重复选取。设置版本号读取应用实际版本。

iOS 在宽度足够时显示三栏；较窄窗口显示记录列表与工具导航，详情通过 NavigationStack 进入。TabView 的具体位置由系统适配，Duo 运行时会使用侧边工具栏。

详情将分类、标题、编辑操作、字段和 Markdown 备注分层。复制与显示密码位于对应字段右侧。银行卡使用仅显示末四位的视觉卡片。正文上限宽度避免大窗口上的超长阅读行。

设置页使用“安全 / 同步与备份 / 外观与关于”分组，不再将所有内容堆在单个长页面。外观支持跟随系统、浅色和深色，立即应用于主窗口和弹窗并在本机记住选择。密码生成器底部固定重新生成和复制操作，规则可独立滚动。

编辑器采用独立可滚动内容和固定保存栏；Mac 登录信息将账号和网址并排，iPhone 保持纵向。所有记录的备注共用 Markdown 编辑／预览组件。密码生成规则沿用本机共享配置，默认 16 位。

### 银行卡卡面

BankCardView、CardAppearancePicker 和 CardThumbnail 统一详情、编辑预览和列表缩略图。卡面采用实体 ID-1 银行卡的 **85.60 × 53.98 mm** 比例（约 1.586:1），内部排版等比缩放，列表小卡也保持相同比例。详细字段仍支持系统字号和复制；图形卡面保留可访问性描述。

| 卡组织 | 借记卡 | 信用卡 | 纹样 |
| --- | --- | --- | --- |
| 银联 | 蓝色金属底 | 深灰金属底 | 右侧斜面浮印 |
| Visa | 深蓝金属底 | 深靛金属底 | 右侧 VISA 浮印 |
| Mastercard | 暖灰金属底 | 炭灰金属底 | 右侧双圆浮印 |
| 运通 | 银灰金属底 | 深灰金属底 | 右侧原创几何人物浮印 |

所有纹样、芯片和标识由 SwiftUI 文字与矢量形状绘制，无远程图片。图形卡面仅显示卡号末四位，不显示安全码。参考总览为 [八种实际卡面](Previews/card-designs.webp)。

卡组织统一为银联、Visa、Mastercard、运通（American Express），借记／信用类型由用户手动选择，不进行卡号前缀识别。百夫长不是卡组织；早期保存的 centurion 标识兼容解码为 americanExpress，新保存使用正确标识。所有卡面使用一致的左上品牌／类型、细分隔线、底部弧光和右侧淡纹。新建卡片默认银联借记卡；旧记录缺失字段时保持中性卡面，可手动选择或恢复中性样式。

卡号输入只保留数字，全角数字转换为半角；粘贴时移除空格、分隔符和字母。实时显示位数，非空卡号检查 8–19 位长度和 Luhn 校验位；全零卡号不通过。超长输入显示错误并禁止保存，不静默截断。未填写卡号仍可保存其他信息；校验失败的非空卡号需修正后保存。Luhn 通过只表示语法和校验位通过，不表示银行已发行或卡片可用。

卡面选择使用新增的可选 cardBrand 和 cardType，随原记录一起加密保存；旧 JSON 记录和草稿可继续解码，无需改变 CloudKit schema。

银行卡编辑将卡面作为辅助预览：足够宽的 Mac 面板采用 240pt 卡面与右侧选项并列；窄屏卡面居中，自适应可用宽度且不超过 260pt，去掉侧边重复的卡组织／类型摘要，下方使用两列组织选项和卡类型分段按钮。Mac 和 iPhone 均不显示配色名称或“实时预览”提示。辅助功能字号改为纵向排列，选项保留至少 44pt 点击区域、选中勾号和 VoiceOver 状态。顶部重置按钮恢复中性卡面，标题区域有独立不透明背景；详情卡面宽度上限为 380pt。两端组件对照见 [紧凑银行卡设置](Previews/card-picker-compact.webp)。

### Markdown 书写面板

`MarkdownComposer` 为登录备注、银行卡备注和安全笔记提供统一的书写面板：自定义书写／预览切换、格式快捷工具、字符计数和右下角的展开编辑按钮。

- Mac：展开为宽面板，可选择书写、预览、左右对照。`⇧⌘E` 展开，`⌘Return` 完成返回。
- iPhone：展开为全屏编辑，提供独立的完成按钮和收起键盘入口，适配键盘与横竖屏。
- 标题、加粗、斜体、列表、Todo、引用、代码块和链接操作作用于当前光标或选区。
- 底层使用 NSTextView / UITextView 保留平台输入、选区与撤销行为；SwiftUI 管理布局和状态。
- 展开和紧凑编辑共用草稿与选区。完成只返回当前表单，最终由记录的保存操作持久化加密内容。
- 模式切换保留原生输入组件，最后一次格式命令不会被重复执行，原生撤销栈也保留。
- 编辑器关闭时提供继续、保留加密草稿、放弃修改三个选择。未保存内容的手势关闭会被阻止。

文字通过 `aegisFont` 和 `ScaledMetric` 跟随系统字号。辅助功能字号下，记录类型选项和保存操作改为纵向布局。浅色辅助文字使用 `#566272`；脚本测试验证正文、辅助文字、主题色和金色在主要背景上的对比度至少 4.5:1。iOS 交互图标保留独立的 44pt 命中区域。

`VaultErrorPresenter` 将错误交给最近打开的界面呈现，覆盖根页面、设置、导入、编辑器和大编辑器；iOS 当前弹窗还会在场景失活时显示隐私遮罩。

## 文案

所有新文案仍位于共享 String Catalog。品牌、用户内容和外部服务名不翻译。产品界面不展示加密参数、Target 名称或构建信息；签名与 CloudKit 配置说明放在项目文档中。
