# UI 设计规范

## 方向

Aegis 使用暖白背景、深墨绿主色和少量暖金。界面层级由留白、文字与背景区分，减少粗分隔线和系统默认蓝色选中块。所有自定义颜色都有深色模式对应值。

## 组件

`App/Views/DesignSystem.swift` 是共享视觉入口，主应用与自动填充扩展共同编译它。

- `AegisTheme`：背景、表面、侧边栏、选中状态、文字和边框的动态颜色。
- `AegisButtonStyle` / `AegisIconButton`：主要、次要和图标操作；iOS 图标按钮使用 44pt 点击区域。
- `AegisInput`：独立标签、输入框和焦点边框。
- `AegisSection`：小节标题与内容面板。
- `AegisSheetHeader`：弹窗标题、说明、图标与关闭入口。
- `ItemIcon`：不同类型与账号的颜色识别，无联网 favicon 请求。
- `AegisPill` / `AegisEmptyState`：辅助状态与空内容引导。

## 布局

Mac 使用可调整宽度的三栏：左侧分类，中间搜索与记录，右侧详情。记录采用可控的浅绿选中背景，选中与失焦都保留清晰的文字对比。列表支持上下方向键选择。

iOS 在宽度足够时显示三栏；较窄窗口显示记录列表与工具导航，详情通过 NavigationStack 进入。TabView 的具体位置由系统适配，Duo 运行时会使用侧边工具栏。

详情将分类、标题、编辑操作、字段和 Markdown 备注分层。复制与显示密码位于对应字段右侧。银行卡使用仅显示末四位的视觉卡片。正文上限宽度避免大窗口上的超长阅读行。

编辑器采用独立可滚动内容和固定保存栏。所有记录的备注共用 Markdown 编辑／预览组件。密码生成规则沿用本机共享配置，默认 16 位。

### Markdown 书写面板

`MarkdownComposer` 为登录备注、银行卡备注和安全笔记提供统一的书写面板：自定义书写／预览切换、格式快捷工具、字符计数和右下角的展开编辑按钮。

- Mac：展开为宽面板，可选择书写、预览、左右对照。`⇧⌘E` 展开，`⌘Return` 完成返回。
- iPhone：展开为全屏编辑，提供独立的完成按钮和收起键盘入口，适配键盘与横竖屏。
- 标题、加粗、斜体、列表、Todo、引用、代码块和链接操作作用于当前光标或选区。
- 底层使用 NSTextView / UITextView 保留平台输入、选区与撤销行为；SwiftUI 管理布局和状态。
- 展开和紧凑编辑共用草稿与选区。完成只返回当前表单，最终由记录的保存操作持久化加密内容。

## 文案

所有新文案仍位于共享 String Catalog。品牌、用户内容和外部服务名不翻译。产品界面不展示加密参数、Target 名称或构建信息；签名与 CloudKit 配置说明放在项目文档中。
